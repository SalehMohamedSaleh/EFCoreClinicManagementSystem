# EFCoreClinicManagementSystem
نظام متكامل لإدارة العيادات الطبية تم بناؤه باستخدام تقنيات .NET و Entity Framework Core. يركز المشروع على تقديم بنية تحتية قوية لإدارة البيانات الطبية وتنظيم العلاقة بين الأطباء والمرضى.

🚀 التقنيات المستخدمة (Tech Stack)
اللغة: C# [.NET].

قاعدة البيانات: SQL Server.

محرر البيانات (ORM): Entity Framework Core.

الأدوات: Visual Studio.

🏗️ البنية المعمارية (Project Architecture)
تم تصميم المشروع باتباع مبادئ Clean Architecture لضمان فصل الاهتمامات وسهولة الصيانة، حيث تم تقسيم المنطق البرمجي كالتالي:

Entities: تحتوي على نماذج البيانات (Data Models) والعلاقات بين الجداول.

Data: تشمل سياق قاعدة البيانات (DbContext) وإعدادات الاتصال.

Services: تحتوي على منطق العمل (Business Logic) والعمليات الأساسية للنظام.

Migrations: لتتبع كافة التغييرات التي تطرأ على هيكل قاعدة البيانات.

🛠️ كيف تبدأ (Getting Started)
لتشغيل المشروع على جهازك المحلي، اتبع الخطوات التالية:

قم بعمل Clone للمستودع.

تأكد من تعديل الـ Connection String في ملف appsettings.json ليتوافق مع خادم SQL الخاص بك.

افتح الـ Package Manager Console وقم بتنفيذ الأمر التالي لتحديث قاعدة البيانات:

Bash
Update-Database
📋 المميزات الأساسية
إدارة بيانات المرضى والأطباء بشكل كامل.

تنظيم الروشتات الطبية والزيارات.

استخدام الـ Repository Pattern لتسهيل التعامل مع البيانات.
